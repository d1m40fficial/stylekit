Как пользоваться

Это шпаргалка дизайн-кита StyleKit: 8 стилей — по вкладке на каждый. Открываешь стиль, смотришь живое демо и правила, копируешь готовую фразу и вставляешь агенту.

Порядок

  1. Выбери вкладку — цифра + название останутся в истории ссылок: …/stylekit/#4-apple-liquid-glass
  2. Посмотри демо — кнопки, карточки, анимации отрисованы в каждом стиле по-настоящему.
  3. Скопируй фразу кнопкой: например «тема целиком», «кнопки», «анимация скролла», «стеклянные панели».
  4. Скажи агенту: «возьми тему как в “Liquid Glass”», «возьми стиль кнопок из 2-го стиля», «возьми анимацию скролла из “Parallax Sections”» — агент-скилл stylekit примет это.

Hand-Drawn Doodle

Развёрнутый дудл · тетрадь с маркерами

Рисованные линии, дудл-иллюстрации, «тетрадный» фон из линованной бумаги, пунктирные рамки и жёсткие офсетные тени цвета маркеров. Тёплый handmade-характер. Анимация: стоп-моушен дрожание на hover.

Parallax Sections

Параллакс-секции · скролл-сторителлинг

Полноэкранные секции с фиксированным фоном (bg-attachment: fixed), скроллящийся контент поверх — эффект глубины. Кинематографичный ритм duration-500/700. Если нужен скролл-эффект — это стиль №2.

Живое демо · background-attachment: fixed

прокрути коробку мышкой / трекпадомсекции минимум 100% высоты

Бренд-история

Фон закреплён, контент едет над ним — глубина без лишних слоёв. Полупрозрачная подложка bg-white/15 + blur для читаемости.

Продукт

Секции min-h-screen сохраняют ритм; акценты глубины через opacity/blur, без резких движений.

Призыв к действию

Короткая финальная секция-склейка с градиентом-переходом.

  • Дёрганые короткие анимации

Shader Gradient

Шейдерный градиент · живой WebGL-фон

Премиум-эстетика в духе Stripe / Linear / Vercel: настоящий WebGL fragment-shader (fbm domain warp) рисует «дышащее» переливающееся поле на почти чёрном канвасе, над ним парят матовые стеклянные панели. Один яркий акцент — фиолетовый #7C5CFF.

Живое демо · реальный WebGL-шейдер

fragment shader рендерится в реальном временипанель — frosted glass (blur 18px)
Начать бесплатно

Живой градиент

fbm domain warp + time uniform · ни одного CSS-градиента и animate-pulse

  • DPR cap 2, resize канваса при изменении
  • Пауза rAF вне экрана; reduced-motion → 1 кадр
  • Фолбэк: статичный CSS-градиент без WebGL
  • Контент только на стеклянных панелях / scrim 4.5:1

Нельзя

  • Фейковый градиент: PNG или CSS-анимация вместо шейдера
  • CSS-стопы-клише from-indigo-600 via-purple-600 to-pink-500
  • animate-pulse, duration-100, много канвасов/акцентов
  • Текст прямо на поле без панели
  • Анимация позиции/теней DOM — отбирает GPU у шейдера

Apple Liquid Glass

Жидкое стекло · WWDC 2025

Язык Apple поверх традиционного глассморфизма: blur 40px + saturate 1.8, радужные ореолы-рамки, градиентные заголовки с толстым stroke и 3D-тенью, большие скругления 24px, «текучие» переходы 500ms.

Paper Craft

Бумажные ремёсла · papercut-слои

Многослойная бумага: карточки слегка повёрнуты, «бумажные» офсетные тени 4–5px, нижние слои на hover раскрываются веером (Layer Separation), тёплый кремовый фон. Для детских/образовательных продуктов и студий.
