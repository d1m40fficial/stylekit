## EN

### Files

- `AI_PROMPT.md` — a single merged prompt for AI coding tools (English + Russian). Start here.
- `DESIGN_SPEC.md` — human-readable design specification (palette, type, motion), English + Russian.
- `tokens/` — per-style design tokens (Figma Tokens / Tokens Studio compatible), CSS variables and Tailwind presets.
- `.opencode/skills/stylekit/SKILL.md` — agent skill: teaches AI tools how to apply styles and borrow single elements (buttons, cards, scroll animations) between styles.

### Cheat sheet / Шпаргалка

Interactive web cheat sheet with one tab per style — open a style, look at the live demo, click a copy-phrase button and paste it to your agent:

> https://d1m40fficial.github.io/stylekit/

### Suggested workflow

1. Paste `AI_PROMPT.md` into your AI tool as the design context.
2. Import `tokens/*.tokens.json` into Figma (Tokens Studio) or wire the Tailwind preset.
3. Or just tell your agent: «возьми тему как в "Liquid Glass"» / «возьми стиль кнопок из второго стиля» / «анимацию скролла из 4».
4. Drop the component snippets in as you build.

## RU

- `AI_PROMPT.md` — единый промпт для AI-инструментов (Cursor, v0, Claude, Copilot), английский + русский.
- `DESIGN_SPEC.md` — человекочитаемая спецификация дизайна (палитра, типографика, анимации), английский + русский.

Интерактивная веб-шпаргалка с вкладкой на каждый стиль — открой стиль, посмотри живой демо, нажми кнопку копирования фразы и вставь её агенту:
